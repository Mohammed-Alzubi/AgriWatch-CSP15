# AgriWatch — Farm Sensor Monitoring and Alert System

AgriWatch is a university software project focused on monitoring farm conditions using simulated sensor readings and delivering timely alerts.

## Project Scope

The proposed pilot covers **4 fields, 2 greenhouses, and 40 simulated sensors**, with readings reported every 5 minutes.

### Planned Features
- Secure user authentication and role-based access
- Sensor, site, and zone management
- Sensor-data ingestion and validation
- Live values and historical charts
- Configurable alert thresholds and notifications
- Alert acknowledgement, escalation, and offline-sensor detection
- CSV exports and management dashboard

## Proposed Technologies

- **Frontend:** React
- **Backend:** Django REST Framework
- **Database:** PostgreSQL
- **Deployment:** Docker
- **Version Control:** Git and GitHub

## Project Status

**Phase 1 — Initiation and Planning.** The project management plan documents the scope, requirements, architecture, schedule, risks, and test strategy. Features and technologies listed here are proposed and are not yet presented as implemented.
